## 上传到 GitHub

1. 解压 ZIP，在 GitHub 新建一个仓库。
2. 使用仓库的文件上传功能，将本文件夹内的文件上传到仓库根目录。不要只上传 ZIP，也不要额外套一层文件夹。
3. 提交后，可以直接查看 Markdown 源文件。

## 以网页展示

在支持 GitHub Pages 的仓库中，进入 Settings → Pages，选择从分支发布，选择 `main` 分支与根目录 `/ (root)` 并保存。构建完成后使用该页面显示的网站地址打开首页。具体选项是否可用取决于仓库和账户设置。

GitHub 仓库中的 HTML 文件通常显示源码；需要使用 Pages 地址，或下载后在浏览器打开，才能阅读排版后的网页。
